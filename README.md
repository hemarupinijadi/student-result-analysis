# Student Result Analysis

## Overview

In this project, I analyzed a student dataset to see how different factors like study hours and other details affect student performance.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## What I Did

* Loaded the dataset and checked the data
* Created graphs to understand patterns in the data
* Used heatmaps to understand relationships between different features

## How to Run

Open the notebook and run all the cells step by step.
